# FINDIT

FINDIT is a lost-and-found management platform.

## Project structure
- `client/`: React frontend using feature-based architecture.
- `server/`: Express backend using MVC + Service Layer.
- `docs/`: architecture, API and team contracts.

## Before implementation
1. Inspect existing files and package configuration.
2. Reuse existing working code.
3. Agree on database schemas and API contracts.
4. Configure environment variables using `.env.example`.
5. Never commit `.env`, API keys, OTPs or tokens.

See `docs/ARCHITECTURE.md`, `docs/API-CONTRACT.md` and `docs/TEAM-OWNERSHIP.md`.
